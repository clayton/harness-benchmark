# Fairness and telemetry

- Controlled studies reject differences outside `varied_axes`.
- Ecological studies permit complete bundles to differ. State those confounds plainly.
- Use seeded randomized order and the same repeat count for every arm and scenario.
- Judge outcome and reliability before efficiency. Compare cost and tokens only for equivalent outcomes.
- Aggregate parent and child-agent usage. Record whether cost is actual or estimated and pin the price snapshot.
- Local Study runs publish as signed Open Range evidence. An origin-scoped publisher signature proves payload integrity, not approved execution. Do not describe `comparison_mode: controlled` as Approved-runner verified evidence.
- Count distinct publishers for replication. Repeated runs from one publisher are not independent reproductions.
- Missing child usage, total tokens, or cost makes efficiency telemetry incomplete.
- Never publish credentials, prompts from private evaluators, local paths, raw logs, or private target refs.
